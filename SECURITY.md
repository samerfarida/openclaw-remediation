# Security policy

## Reporting a vulnerability

If you believe you have found a security issue related to **this repository** (e.g. the uninstall scripts or CI workflow), please report it responsibly:

- **Preferred**: Open a GitHub Security Advisory (Repository → Security → Advisories → New draft), or
- Open a private issue and mention that it is security-sensitive.

Please do **not** disclose the issue publicly before it has been addressed.

## Scope

- **This project** provides detection, uninstall, and validation tooling for [OpenClaw](https://openclaw.ai/). It does **not** classify OpenClaw as malware and uses only publicly documented uninstall mechanisms.
- **OpenClaw itself**: For security issues in OpenClaw (the upstream project), please report to [OpenClaw’s security process](https://docs.openclaw.ai/gateway/security) (e.g. security@openclaw.ai as referenced in their docs).

We will respond to valid reports about this repo and work with you to resolve issues in a reasonable timeframe.
